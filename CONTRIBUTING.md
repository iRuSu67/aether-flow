# Contributing to AetherFlow

We welcome contributions from systems architects, AI engineers, and open-source enthusiasts!

## Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/iRuSu67/aether-flow.git
   cd aether-flow
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Build all packages**:
   ```bash
   npm run build
   ```

4. **Run the test suite**:
   ```bash
   npm test
   ```

5. **Start the visual canvas**:
   ```bash
   npm run start:canvas
   ```

## Pull Request Guidelines
- Follow TypeScript strict mode conventions.
- Ensure all unit tests pass with `npm test`.
- Add tests for new agent behaviors or sandbox extensions.
- Keep commits concise and meaningful (`feat:`, `fix:`, `docs:`, `perf:`).
